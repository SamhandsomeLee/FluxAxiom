## 方法

测试：`crates/run-host/tests/context_corpus.rs` 的 `corpus_of_mini_inventory_run`。命令是 `cargo test -p fluxaxiom-run-host --test context_corpus corpus_of_mini_inventory_run -- --exact --nocapture`。库以只读方式打开 `%LOCALAPPDATA%\FluxAxiom\host.db`，不跑迁移，也不扫描租约。

样本是 2026-10-26 的 Run `run_01a175b8-f488-77ed-b6ea-153e72ff7616`。6 次 `model.call_completed`，11 次 `tool.call_completed`。消息占比取最后一次请求，因为它包含这次 Run 的全部历史。字节是 `content` 的 UTF-8 长度。`reasoning_content` 另计，不并进这个分母。

这 11 条工具事件没有 `tool_call_id`。参数按最后一次请求里 `tool_calls` 的出现顺序对齐。两边的工具名顺序相同。完全重复是更早一次的工具名、规范化参数和结果引用都相同。同文件重读只数 `read_file`：同一路径上第一次之后的调用。后一次 `start_line` 不大于同路径更早一次时，另计一对可能覆盖。stdout 没有 prompt、思维链或工具正文。
