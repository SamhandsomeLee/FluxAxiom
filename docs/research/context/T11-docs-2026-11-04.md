# T11 记录：压缩参数、价格与版本

核对日期：2026-11-04。不调用 API，不改档案，也不把离线分词接进运行路径。

## 方法

Chat Completions 参数表来自 <https://api-docs.deepseek.com/zh-cn/api/create-chat-completion>。价格和版本来自 <https://api-docs.deepseek.com/zh-cn/quick_start/pricing>。离线分词说明来自 <https://api-docs.deepseek.com/zh-cn/quick_start/token_usage>。压缩块只查已经保存的 T8 记录，不重跑探针。

版本对照三处：价格页的模型版本、档案 `crates/context/profiles/deepseek-deepseek-flash.toml` 的 `doc_version`、`crates/engine-custom/src/doc_version.rs` 里 `deepseek-flash` 那一行。

## 压缩参数

这次读到的请求字段有 `model`、`thinking`、`reasoning_effort`、`max_tokens`、`response_format`、`stop`、`stream`、`stream_options`、`temperature`、`top_p`、`tools`、`tool_choice`、`logprobs`、`top_logprobs`，以及标成 deprecated 的 `frequency_penalty`、`presence_penalty`。参数表里没有压缩参数，页面正文里也没有「压缩」或 compaction。

五份 T8 记录只留了字数、`prompt_tokens` 差、比例和 HTTP 类别。它们写明 completion 没有从输出里取得。保存的材料里没有响应正文，所以看不出普通响应里有没有无法由分词解释的压缩块。这不写成「没有压缩块」。

## 价格

单位是人民币 / 百万 tokens。空闲时段是高峰时段的一半。北京时间周一至周五、不含中国法定节假日，9:00–12:00 和 14:00–18:00 是高峰；其余时间，包括周末和法定节假日全天，是空闲。

| 档 | 空闲 | 高峰 |
| --- | ---: | ---: |
| `deepseek-flash` 输入，缓存命中 | 0.02 元 | 0.04 元 |
| `deepseek-flash` 输入，缓存未命中 | 1 元 | 2 元 |
| `deepseek-flash` 输出 | 4 元 | 8 元 |

## 版本

价格页写的是 `DeepSeek-V4.1-Flash-1017`。`doc_version.rs` 的 `deepseek-flash` 行也是 `DeepSeek-V4.1-Flash-1017`，`checked_at` 是 `2026-10-21`。档案 `doc_version` 的取值是 `V4.1-Flash-1017`，没有 `DeepSeek-` 前缀。三处都指向同一版标签，字符串不完全相同。这次不改小表，也不改档案。

## 离线分词

用量页给出的压缩包地址是 <https://cdn.deepseek.com/api-docs/deepseek_v4_tokenizer.zip>。包内脚本用 `transformers` 对一段原始文本做 `encode`，示例是 `Hello!`。本机 Python 是 3.12.10，没有 `transformers`，脚本没有跑。没有和 T8 的 `prompt_tokens` 比较。分词器偏差保持未测。

## 结论

Chat Completions 参数表没有列出压缩参数。响应里的压缩块没有可核对的正文，所以 `native_context_mgmt` 仍不改，档案里继续是假设。价格和版本如上。离线分词包没有在本机运行。
